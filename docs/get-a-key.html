Getting your AI key

Proof's AI features use Anthropic's Claude, and they need an API key — a long code starting with sk-ant- that Proof uses to talk to Claude on your behalf.

Did someone give you a key?

Paste it into Proof's welcome screen. That's it — you're done.

Getting your own key (about 3 minutes)

  1. Create an account at console.anthropic.com. This is a separate, pay-as-you-go developer account — it does not require a Claude subscription.
  2. Add a small amount of credit under Billing.
  3. Go to API Keys, create a key, and copy it.
  4. Paste it into Proof's welcome screen (or later under Settings).

The Anthropic console shows exactly what you've used, and Proof has its own usage meter under Settings so you can check anytime.
